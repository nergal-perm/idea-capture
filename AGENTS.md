# Project guidance

Read [README.md](README.md) for the product scope, current state, configuration,
and secret-check hook. For the existing Omarchy client, read
[apps/omarchy/README.md](apps/omarchy/README.md) before changing it.

Write all project documentation in English. Communicate with the owner in
Russian in chat.

Keep machine-specific paths, live configuration, credentials, and personal
notes outside the repository. Use external configuration and neutral examples.

Create commits or push changes only when the owner explicitly asks.
